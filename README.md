# README – Aplikacja do nauki wzorów skróconego mnożenia

## Opis projektu

Aplikacja edukacyjna stworzona w React pomagająca w nauce i utrwalaniu wzorów skróconego mnożenia. Umożliwia rozwiązywanie przykładowych zadań matematycznych oraz wyświetlanie szczegółowych rozwiązań krok po kroku.

## Funkcjonalności

- Wybór zadań z listy dostępnych przykładów.
- Nauka wzoru na różnicę kwadratów: \(a^2-b^2\).
- Nauka wzoru na różnicę potęg: \(a^n-b^n\).
- Wyświetlanie rozwiązań krok po kroku.
- Automatyczne obliczanie wyników.
- Możliwość pokazywania i ukrywania rozwiązań.
- Wyświetlanie informacji o zadaniach pochodzących z arkuszy maturalnych.

## Wykorzystane technologie

- **React** – budowa interfejsu aplikacji.
- **JavaScript** – obsługa logiki i obliczeń matematycznych.
- **KaTeX (react-katex)** – wyświetlanie wzorów matematycznych.
- **JSON** – przechowywanie przykładowych zadań i danych.

## Cel aplikacji

Aplikacja ma ułatwić zrozumienie i zapamiętanie wzorów skróconego mnożenia poprzez praktyczne przykłady oraz prezentowanie kolejnych etapów rozwiązywania zadań.

## Dla kogo?

Aplikacja jest przeznaczona przede wszystkim dla uczniów szkół podstawowych i średnich, którzy chcą szybko i skutecznie opanować korzystanie z wzorów skróconego mnożenia.

## Jak korzystać z aplikacji?

1. Wybierz interesujący Cię rodzaj wzoru.
2. Wybierz zadanie z dostępnej listy.
3. Zapoznaj się z wyświetlonym przykładem.
4. Spróbuj rozwiązać zadanie samodzielnie.
5. Kliknij przycisk „Zobacz rozwiązanie”, aby wyświetlić kolejne etapy obliczeń i sprawdź czy są podobne do tego co zapisałeś.
6. Kliknij „Ukryj rozwiązanie”, gdy uznasz, że rozumiesz już sposób rozwiązywania tego zadania.
7. Za pomocą przycisku „Ukryj wszystkie zadania” możesz wyczyścić aktualnie wybrane przykłady.
